# Андрей & Екатерина — приглашение на свадьбу 27.02.2027

Сайт-приглашение. При открытии гость видит конверт, нажимает на печать, и открывается приглашение.
Сборки нет, зависимостей нет: всё лежит в репозитории.

## Что внутри

```
index.html                  — сайт (стили и скрипт внутри)
assets/img/                 — фотографии
assets/fonts/               — шрифты (Cormorant Garamond, Cormorant Unicase, Great Vibes)
invite-single-file.html     — то же приглашение одним файлом: шрифты и фото встроены, можно отправить файлом
.nojekyll                   — GitHub Pages отдаёт файлы как есть
```

## Как опубликовать на GitHub Pages

1. На github.com нажмите **New repository**. Задайте имя, например `wedding`, и тип **Public**. Нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**.
3. Распакуйте архив и перетащите в окно браузера **содержимое** папки `wedding-invite-site`: `index.html`, папку `assets` и остальные файлы. Перетаскивать нужно не саму папку и не zip-архив.
   `.nojekyll` — скрытый файл. Если система его не показывает, ничего страшного: сайт работает и без него.
4. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите *Source: Deploy from a branch*, *Branch: `main`* и папку */ (root)*. Нажмите **Save**.
6. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
   Этот же адрес показан наверху раздела **Settings → Pages**.

Перед отправкой гостям откройте ссылку на телефоне и проверьте, что видны конверт, фотографии и шрифты.

## Что можно настроить

Откройте `index.html`. Его можно править прямо на GitHub кнопкой с карандашом. Найдите блок `const CONFIG`:

```js
const CONFIG = {
  endpoint: '',   // адрес приёма ответов гостей (Google Apps Script)
  vkUrl: '',      // ссылка на группу ВКонтакте — под QR-кодом появится кнопка
  music: '',      // музыка, например 'assets/music.mp3'
  ...
};
```

- **Ответы гостей.** Пока `endpoint` пустой, ответ сохраняется только в браузере гостя. Чтобы ответы приходили в Google-таблицу,
  выполните инструкцию в комментарии над `const CONFIG` (поиск по «Apps Script»). Полученный адрес вставьте в `endpoint`.
- **Музыка.** Загрузите mp3 в папку `assets`, например `assets/music.mp3`, и укажите этот путь в `music`.
  Музыка начнёт играть, когда гость нажмёт на печать конверта: браузеры разрешают звук только после касания. В шапке появится кнопка звука.
- **Тексты.** Все тексты лежат в `index.html` обычным текстом. Ищите нужную фразу поиском.
- **Фотографии.** Замените файлы в `assets/img/`, сохранив имена.

## Превью ссылки в мессенджерах

Чтобы при отправке ссылки показывалась картинка, добавьте в `<head>` файла `index.html` строку с **полным** адресом:

```html
<meta property="og:image" content="https://<ваш-логин>.github.io/<имя-репозитория>/assets/img/hero.jpg">
```
